(* This file is NOT a self-contained tripwire. It is the proof    *)

(*                                                               *)
(* WHAT THE HOP IS. One endpoint derives the KDF key by ENCODING  *)
(* the challenger's random shared secret; the other draws that    *)
(* key directly. Three things have to line up at once:            *)
(*  1. a REORDER -- one side draws the key before its key         *)
(*     generation, the other after its encapsulation (so unlike   *)
(*     the bundled-delegate reorder, a SAMPLE has to move, not    *)
(*     just a call);                                              *)
(*  2. a one-sided `deterministic injective` encoding call,       *)
(*     dropped by its `_det` axiom once its result is             *)
(*     characterized;                                             *)
(*  3. two KDF inputs built from the SAME five leaves under       *)
(*     DIFFERENT bracketings -- closed by `concat_regroup5`.      *)
(*                                                               *)
(* THE CONTENT is the `rnd ev_encodesharedsecret _bij_g` step:    *)
(* the two draws agree because an injective ENDO-map on a finite  *)
(* type is bijective, so encoding a uniform shared secret is      *)
(* uniform. That bijectivity is DERIVED from the licensed `_inj`  *)
(* axiom (see bitword_injective_bijective.ec), never assumed --   *)
(* the export adds NO new trusted base for this hop.              *)
(*                                                               *)
(* WHY THE EMISSION IS PARKED. Every STRUCTURAL fact the route    *)
(* needs is readable off the first flat states -- which side      *)
(* carries the extra call, the swap sequence, the seq split       *)
(* points, the leaf correspondence. The NAMES are not. A          *)
(* challenger-inlined field is `challenger_<f>` in the flat state *)
(* but `<ChalMod>.<f>` after `inline *`; a reduction field is     *)
(* bare in the flat state but `<Red>.<f>` after. This script      *)
(* needs three such names (`RB.ss_PQ`,                            *)
(* `H_c.KDFPRFSec_Real.k`, `KEM_PQ_c.KEM_INDCCA_Random.ctStar`),  *)
(* and no flat state carries them. Unblocking it means resolving  *)
(* `step.reduction` / `step.challenger` to their field sets in    *)
(* the exporter -- where those ASTs live -- and threading a       *)
(* flat->real name map into the route.                            *)
(*                                                               *)
(* LADDER NOTE: the prefix peel ends `wp.` then `skip => /#.`     *)
(* The trailing `wp` is load-bearing -- a peel round's `wp` runs  *)
(* BEFORE its coupling, so it never absorbs an assignment sitting *)
(* ABOVE the run's first call.                                    *)
(* ============================================================ *)
